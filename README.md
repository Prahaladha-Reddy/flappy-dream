# Flappy Dream

A click-through visual explainer of a Flappy Bird world model: a 172.5M-parameter diffusion transformer that draws the game frame by frame from the last 15 frames and the key pressed.

Read it: https://prahaladha-reddy.github.io/flappy-dream/

Weights: https://huggingface.co/Prahaladha/flappy-world-model
